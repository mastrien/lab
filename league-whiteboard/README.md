# League Whiteboard

O **League Whiteboard** é um projeto voltado a explicações de itemização no jogo *League of Legends*. O objetivo é permitir que os usuários analisem, simulem e comparem as mecânicas de itens, runas e builds de forma visual e interativa.

## Documentos do Projeto

*   [Plano do Projeto (PLAN.md)](file:///C:/root_lab/antigravity/lab/league-whiteboard/PLAN.md) — Contém o resumo do projeto, perguntas estruturantes para amadurecer a ideia e o levantamento detalhado sobre a disponibilidade e endpoints de dados oficiais da Riot Games (Data Dragon, CDragon, etc.).

## Tecnologias Propostas
*   Frontend Interativo (HTML5 Canvas ou React Flow / React / TypeScript).
*   Consumo de dados estáticos do Data Dragon/Community Dragon para ícones e atributos de Campeões, Itens e Runas.
